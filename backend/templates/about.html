💧 AI Water Quality Prediction System

This project predicts the quality of water using Machine Learning and Deep Learning techniques. Users enter important water parameters and the AI predicts whether the water quality is Excellent, Good, Moderate, Poor or Unsafe.

Python

Backend developed using Flask Framework.

Machine Learning

Random Forest model predicts water quality.

Deep Learning

TensorFlow Neural Network compares prediction accuracy.

Dataset

20000 Water Quality Samples with WQI and Quality Labels.

Project Features

  • ✔ AI Based Water Quality Prediction
  • ✔ Machine Learning Model
  • ✔ Deep Learning Model
  • ✔ Dashboard Analytics
  • ✔ State-wise Water Analysis
  • ✔ Modern Responsive Website
  • ✔ Flask Backend

Developed using Python, Flask, TensorFlow, Scikit-Learn, HTML, CSS and JavaScript.
